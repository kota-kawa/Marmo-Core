# 0006. プロバイダ失敗はタスクを `failed` で終端させ、監査ログを残す

- 状態: Accepted
- 日付: 2026-09-17
- 根拠: 2080be3c（PR #12）、CHANGELOG 0.5.0

## 文脈

プロバイダの例外がカーネルの外に出ると、`--audit-log` は 1 行も書かれず、副作用のある
ツールは実行済みなのにタスクは `running` のまま残り、`resume` もできなかった。

## 判断

- `ProviderError` はカーネル内で捕まえ、タスクを `failed` で終端し、`audit("task")` を
  書き、`--audit-log` は失敗時にも書き出す。
- CLI の終了コードは、例外扱いの 2 ではなく「終端した失敗」の 1 とする。
- プロバイダのメッセージは伏せ字を通して監査ログとタスク状態に記録する。

## 影響

- 自動化スクリプトはプロバイダ失敗で exit 1 を受け取る（以前は 2）。CHANGELOG に明記。
- 監査ログは常に完全になる。ハッシュチェーンの検証も失敗時に成立する。

## 代替案

- 例外をそのまま伝播させる: 監査の欠落と `running` のまま残るタスクが残るため却下。
