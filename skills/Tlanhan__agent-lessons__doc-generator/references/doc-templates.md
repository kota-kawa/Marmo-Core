# 文档模板库

## 模板 A：函数/方法文档

```
### `函数名(参数列表)`

**功能**：一句话说清楚这个函数做什么。

**参数**：
| 参数名 | 类型 | 说明 |
|-------|------|------|
| param1 | string | 描述 |

**返回值**：类型 + 说明

**示例**：
\`\`\`语言
// 调用示例
\`\`\`
```

## 模板 B：类/模块文档

```
## `类名`

**职责**：这个类负责什么（单一职责描述）。

**主要方法**：
- `method1()` — 简短说明
- `method2()` — 简短说明

**使用场景**：什么时候应该用这个类。
```
